# Internal Linking Map

```
Home ─┬─> Available ──> Artwork ──┬─> Collection(s)
      ├─> Collections ─> Collection ─┬─> Artworks (gallery)
      │                              ├─> Related Journal posts
      │                              └─> Commission CTA
      ├─> Commission <── (every collection, sold work, artwork-sold, blog CTA)
      ├─> Trade hub ──> Designer / Consultant / Buyer's Agent / Corporate
      └─> Journal ──> Post ──> related Collection + Available/Commission CTA

Artwork ──> its Mockups (in-situ)   Mockup ──> back to its Artwork ──> enquiry
Footer ──> all collections, all trade programs, legal, email capture (every page)
Breadcrumbs ──> Home > section > entity (every deep page, + BreadcrumbList schema)
```

## Rules
- Every artwork links to ≥1 collection + ≥3 related works + its mockups.
- Every collection links to its works, ≥1 journal post, and a commission CTA.
- Every blog post links to a related collection and a conversion CTA.
- Sold works funnel to commission; mockups funnel to the underlying artwork's enquiry form.
