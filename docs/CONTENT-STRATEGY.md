# Content Strategy

## Pillars
1. **Collections as hubs** — 10 keyword-aligned collection pages anchor topical authority.
2. **Artworks as long-tail spokes** — 50 (→500+) uniquely-described pages, each rank-capable.
3. **Mockups as proof + image SEO** — 50 in-situ pages with descriptive alt/captions, linking to works.
4. **Journal as intent capture** — 50 guides mapped to collector / designer / architect / homeowner
   questions, each funnelling to a collection + conversion CTA.

## Editorial cadence (suggested)
- 2 new artworks/week as inventory allows (keeps Available fresh, sitemap active).
- 1 journal guide/week targeting a question keyword; interlink to the most relevant collection.
- Refresh mockups whenever a flagship work is photographed in situ.

## Conversion pathways per audience
- Collectors → Available / Artwork enquiry / collector email list.
- Designers & consultants → Trade programs → trade application.
- Architects / developers / corporate → Corporate services → commission/consultation.
- Buyer's agents → Buyer's Agent program → fast-turnaround available works.
