Master interior photographs go here.

Naming: use the scene id, e.g. `coastal-living-room.jpg`.

Requirements for a usable scene:
- A clear, uncluttered wall with room for a large work at eye level
- Ideally shot square-on or near it; strong angles work but need careful calibration
- Something of known size in frame for reference: a door, a sofa, a dining chair
- Even, natural light with a clear direction
- At least 2400 px on the long edge
- No existing artwork on the target wall

After adding a photo, run `python3 scripts/ingest-scenes.py`, then calibrate it in
`mockups/scenes.json` following `mockups/README.md`.
